# Android-Docs-Sample-Code
This repository contains the sample code referenced in the Android Documentation and covers both Kotlin and Java.

**SDK Version**  
These samples all use Version 4.0+ of the Android SDK.

**Using the sample code**
* It is recommended to clone or download the entire repository with all the samples.

**Android Documentation**  
The documentation that references this sample code can be viewed [here](https://docs.atrius.com/docs/getting-started-1.
